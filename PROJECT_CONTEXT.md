# SpectralEarth Research Project Context

## Project Goal

This project aims to develop a novel active learning framework for hyperspectral image classification using a frozen foundation model.

The objective is NOT to develop a new backbone architecture.

The backbone has already been selected after evaluation.

The research contribution is the complete active learning framework built on top of the frozen backbone.

# Phase 2 (Current)

The goal is to transform the project into a complete active learning framework.

The backbone must remain frozen.

Only the classifier head should be updated during active learning.

---

## Model A (Learning Engine)

Already exists inside the project.

Responsibilities:

- Frozen SpectralEarth backbone
- Feature extraction
- Embedding generation
- Classifier
- Training
- Retraining
- Dataset updates
- Prediction probabilities

Model A should NEVER implement uncertainty or diversity algorithms.

---

## Model B (Query Engine)

Already copied into:

src/query_engine/

Responsibilities:

- Entropy uncertainty
- Margin Sampling
- Least Confidence
- Diversity-aware selection
- Adaptive query strategy
- Sample ranking
- Top-K sample selection

Model B should remain an independent module.

# Integration Requirements

The Query Engine must be integrated through imports and function calls.

Do NOT merge its internal files into existing modules.

Maintain modular architecture.

---

# Important Constraints

1. Do NOT modify SpectralEarth architecture.

2. Do NOT redesign the backbone.

3. Keep the current Hydra configuration.

4. Preserve the Lightning training pipeline.

5. Preserve all dataset implementations.

6. Preserve current evaluation metrics.

7. Train ONLY the classifier head after freezing the backbone.

8. Use embeddings generated by SpectralEarth.

9. Query Engine should receive:

- embeddings
- prediction probabilities
- k

and return only

selected sample indices.
